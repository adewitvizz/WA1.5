# Workshop assignment 1.5: Dutch Cone Test


In this workshop, you will investigate the dependence between two measurements from a Cone Penetration Test (CPT): cone resistance ($q_c$) and sleeve friction ($f_s$). You will quantify their dependence using covariance and correlation, fit a bivariate Gaussian distribution to the observations, calculate joint probabilities, and explore conditional Gaussian distributions.

Before you can start this assignment, read the relevant theory pages in the book.

In this assignment you’ll make exercises on the following topics:

- [Bivariate Gaussian distribution with CPT data](./Bivariate_Gaussian_CPT.ipynb)
- Covariance and correlation
- Bivariate Gaussian distributions
- Joint probability calculations
- Independence and dependence
- Conditional Gaussian distributions
